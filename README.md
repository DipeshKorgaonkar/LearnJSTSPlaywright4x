# LearnJSTSPlaywright4x

A collection of hands-on examples for learning JavaScript fundamentals and test automation concepts.

## JavaScript examples

The numbered folders organize examples by topic, including JavaScript basics, keywords and identifiers, operators, conditional statements, switch statements, user input, and loops.

### Keywords and identifiers

The [`02_Chapter_keyword_Identifier/09_IQ.js`](./02_Chapter_keyword_Identifier/09_IQ.js) lesson demonstrates valid JavaScript identifier forms, including names that begin with letters, underscores, or dollar signs; Unicode identifiers; and common naming conventions such as `camelCase`, `snake_case`, and `SCREAMING_SNAKE_CASE`. Invalid identifier examples are included as comments because they would cause syntax errors if executed.

Run the lesson with Node.js from the repository root:

```sh
node 02_Chapter_keyword_Identifier/09_IQ.js
```

Most examples are standalone scripts and can be run in the same way by passing their file path to `node`.

## Requirements

- [Node.js](https://nodejs.org/) for running the JavaScript examples

The root `npm test` script is currently a placeholder and does not run a test suite.
